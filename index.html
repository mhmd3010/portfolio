About me

Hi, I'm Mahmud. I'm a full-stack developer and network engineer living in Dhaka, and my area of expertise mostly overlaps the two: the software used by the ISP, and the network on which it operates.

From the software side I develop mostly in PHP, Python and Go, using the base software called PHPNuxBill and its plugins for EPON OLT management, accounting, improved hotspots, and payment gateway software which were not originally included in this platform.

Network-wise I've worked with Cisco, RouterOS, pfSense , etc: multi-WAN with failover, OLT/ONU provisioning, VLAN segregation, and Zabbix monitoring which alerts of problems even before any of the subscribers call in.

The overlapping of the two fields is the main idea here. Billing issues resulting from routing loops or "slow internet" due to uplink queues - I'm able to trace that all the way back instead of sending it somewhere midway.
